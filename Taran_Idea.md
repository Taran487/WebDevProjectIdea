# Project idea 1

## campus Club management system
This website will allow users to manage clubs of a campus, events, announcements and user accounts as well. All these features will have CRUD implementation.
## Features
### user accounts
Register
Login/Logout
View profile
Edit profile
Delete account
### club management
Create a new club
View all clubs
Edit club information
Delete a club
### Event Management
Create events for clubs
View upcoming events
Update event details
Delete events
### Announcements
Post announcements for clubs
View announcements
Edit announcements
Delete announcements
## DB Tables
users
clubs
events
announcements
## Website pages
Home
Login/Register
Dashboard
Clubs
Club Details
Events
Announcements
Profile
